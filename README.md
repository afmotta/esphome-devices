# esphome-devices

ESPHome firmware, hardware sources and configuration for a three-floor residence's home
automation: CAN-bus wall buttons and room sensors, lighting control, and multi-zone
climate control (radiant floor + fancoil, with ventilation). The whole system is
pre-live — hardware is standardized and the firmware is built, but nothing is
physically deployed yet.

## What's where

A layered monorepo: one shared infrastructure layer, two application systems on top of
it, and the PCB sources for the CAN boards.

| Directory | Layer | What it is | Rules |
|---|---|---|---|
| [`canbus/`](canbus/) | infrastructure | CAN transport: frames, heartbeats, node discovery/health, generated node firmware | [`canbus/CLAUDE.md`](canbus/CLAUDE.md) |
| [`lighting/`](lighting/) | application | Button decode → Home Assistant events, hold automations | [`lighting/CLAUDE.md`](lighting/CLAUDE.md) |
| [`climate/`](climate/) | application | Multi-zone heating/cooling/ventilation controller | [`climate/CLAUDE.md`](climate/CLAUDE.md) |
| [`hardware/`](hardware/) | PCB sources | KiCad projects (generated by script) of the CAN wall node and the CAN bridge | [`hardware/README.md`](hardware/README.md) |
| [`registry/`](registry/) | system of record | Node table, bindings, `map.json` | [`registry/README.md`](registry/README.md) |
| `devices/`, `boards/`, `packages/` | composition | Deployable entry points, board definitions, shared packages | root [`CLAUDE.md`](CLAUDE.md) |
| [`docs/`](docs/) | knowledge base | ADRs, architecture, contracts, live climate docs, `archive/` | [`docs/adr/`](docs/adr/) |

## Maintenance & Support Guide

**[afmotta.github.io/esphome-devices](https://afmotta.github.io/esphome-devices/)** —
the practical guide for keeping this system running: everyday monitoring, diagnosing
common problems, and step-by-step hardware-replacement procedures. Written for
someone who doesn't need to know the codebase — a technician, a family member, or
future-you standing next to a dead piece of hardware having scanned a QR code.
Available in [English](https://afmotta.github.io/esphome-devices/) and
[Italiano](https://afmotta.github.io/esphome-devices/it/).
